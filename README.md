# TFT Trait Ladder

[Open the calculator](https://5o1.github.io/tft-trait-ladder/) · [简体中文](README.zh-CN.md)

TFT Trait Ladder is a web calculator for Set 18: Enchanted Wilds in Teamfight Tactics and Golden Spatula. It finds lineups for different numbers of active traits and ranks them by the estimated difficulty of finding their champions in the shop.

The optimizer accounts for owned champions, emblems, extra team slots, Kha'Zix evolutions, and Lux forms. The interface supports English and Simplified Chinese.
